# 데모 구현 계획

> 최신 상태 (2026-11-09): 사용자 후속 요청으로 강의노트 구현이 승인되어 세 종류 생성·키 설정·취소·PDF 기능을 구현했다. 외부 API 실호출과 사용자 무료 프로젝트/노트 품질 검증은 아직 미실행이다. 기존 전사 기능은 유지한다. 아래의 설계만 승인/미구현 표현은 이전 단계 기록이며 현재 상태는 IMPLEMENTATION_STATUS.md의 마지막 항목을 따른다.


후속 구현 요청에 따라 아래 세 단계를 구현했습니다. 검증 근거와 남은 사용자 샘플 확인은 IMPLEMENTATION_STATUS.md를 참고합니다. 이전 M0~M6의 전체 앱 계획을 계속 진행하지 않습니다.

## 1 모델 준비와 단일 전사

현재 환경에서 faster-whisper 호환 버전을 확인하고 의존성을 잠급니다. 다국어 base·small을 명시적 준비 단계에서 내려받습니다. 짧은 한국어 샘플로 두 모델의 로컬 전사를 실제 실행합니다.

완료 조건: 선택한 모델별 결과·소요 시간 확인. 가짜 전사나 아카이브의 모델 기본값만으로 통과 처리하지 않습니다.

## 2 데모 화면과 처리 연결

한 파일 선택, 모델 드롭다운, 시작 버튼, 처리 상태, 읽기 전용 전사문을 연결합니다. 기존 보관함 화면을 데모 화면으로 바꿉니다. 실행 잠금·루프백·세션 보호를 재사용합니다.

완료 조건: 선택 모델이 서버 작업에 반영되고 중복 시작이 막히며 실패 후 다시 실행 가능.

## 3 다운로드와 시연 확인

시간 없는 UTF-8 Markdown 다운로드를 연결합니다. 파일 교체·모델 변경 때 오래된 결과가 남지 않도록 합니다. 임시 파일 정리와 결과 수명을 검증합니다.

완료 조건: D01~D05 통과, 대표 시연 파일과 소요 시간 기록, 모델 준비 후 네트워크 차단 상태에서 사용 흐름 통과.

## 사용자가 준비할 것

갤럭시 녹음 1~5분을 PC에 준비합니다. 영어 전공용어가 포함되면 모델 비교에 도움이 됩니다. 정답 전사문은 품질 비교에 유용하지만 데모 흐름 구현을 시작하는 필수 조건은 아닙니다. API 키·Google 프로젝트는 필요 없습니다.

## 강의노트 후속 구현 순서 (아직 시작하지 않음)

| 단계 | 작업 | 완료 판단 |
| --- | --- | --- |
| N0 | 별도 구현 요청 후 최종 전사 segment/복구 시간 매핑, 무료 프로젝트·모델 한도, 구조화 응답/키 저장/PDF 후보 확인 | 미확정 기술값의 근거 기록, 원래 전사 불변 |
| N1 | 모의 API로 이해용 전체 흐름: 키 설정, 탭, 작업 상태, 취소·180초 제한, 오류, 공통 문서 구조, PDF | 원문 보존, 실패 시 기존 결과 유지, 개인정보/동시성/렌더 검증 |
| N2 | 외부 전송 가능한 짧은 샘플로 이해용 실제 생성·화면·PDF | 클릭에 의한 단일 요청, 완전한 결과, API 사용/지연 기록 |
| N3 | 암기용·문제풀이용 추가, 종류별 유지·재생성, 3종 PDF | 문제-정답 대응, 보충 표시, 종류 전환 API 미호출 |
| N4 | 같은 49분 전사 snapshot으로 3종 품질 평가·수정 | 정확성 우선 사용자 검토, 미해결 문제 명시, 필요 시 유료 비교 별도 결정 |

[검증 계획](STUDY_NOTES_TEST_PLAN.md)을 단계마다 적용한다. 기존 ASR 회귀 검증을 유지한다. 키는 사용자가 향후 앱에 직접 입력하며 이번 문서 단계에서 요구하지 않는다. 무료 정책·실제 모델·결제 상태를 확인하기 전 무과금을 보장하지 않는다.

## 현재 단계

N0의 전사 구간 연결·키 저장·PDF 선택 완료, 무료 프로젝트 접근성과 실제 품질은 사용자 키 입력 후 확인한다. 이해용 공통 흐름과 로컬 테스트를 바탕으로 나머지 두 종류를 구현했다. N1/N3 로컬 기능은 검증 완료, N2/N4 실제 생성 시험은 대기다. 사용자는 AI Studio 무료 프로젝트 키와 외부 전송 가능한 약 3분 전사문을 준비한다. 최초 성공 후 동일 49분 snapshot으로 세 종류를 평가한다. 미검증 모델을 검증 완료로 표시하지 않는다.
