# 데모 실행과 시연

> 최신 상태 (2026-11-09): 사용자 후속 요청으로 강의노트 구현이 승인되어 세 종류 생성·키 설정·취소·PDF 기능을 구현했다. 외부 API 실호출과 사용자 무료 프로젝트/노트 품질 검증은 아직 미실행이다. 기존 전사 기능은 유지한다. 아래의 설계만 승인/미구현 표현은 이전 단계 기록이며 현재 상태는 IMPLEMENTATION_STATUS.md의 마지막 항목을 따른다.


README의 설치·실행 명령을 사용합니다. 현재 PC에는 가상환경과 Base·Small 모델이 준비되어 있습니다. start.cmd가 임의 루프백 포트에 서버를 열고 브라우저를 자동으로 띄웁니다.

1. 갤럭시 녹음 1~5분을 PC로 옮깁니다.
2. start.cmd를 실행합니다.
3. 파일과 모델을 선택하고 전사를 시작합니다.
4. 결과를 확인하고 Markdown을 다운로드합니다.
5. 앱 종료 버튼을 누릅니다.

한 번에 파일 한 개, 200MiB 이하입니다. 모델 준비는 인터넷이 필요하고 전사 요청 중 자동 다운로드는 하지 않습니다. 미설치 모델은 prepare-models.cmd로 준비합니다. API 키는 필요 없습니다.

결과는 서버 메모리에만 존재합니다. 완료 후 30분 내 다운로드하세요. 새 작업·서버 종료 시 결과가 사라지고 새로고침 후 복원 UI가 없습니다. 원본 녹음과 다운로드 파일은 직접 관리합니다.

작업 중 종료 시 확인 후 추론을 중단합니다. 탭만 닫으면 서버가 남을 수 있으므로 앱 종료 또는 터미널 Ctrl+C를 사용합니다. 중복 실행은 차단합니다. 임시 업로드는 %LOCALAPPDATA%/LectureTranscriber/demo-temp에 저장하고 성공·실패·정상 종료 또는 다음 실행 시 정리합니다. 기존 보관함 DB를 삭제하지 않습니다.

친구용 설치 프로그램·자동 업데이트·장시간 처리 보장은 데모 범위가 아닙니다.

## 향후 강의노트 운영 (설계만 승인)

현재 실행 앱에는 노트 기능이 없다. 구현 후 사용자가 앱에 Gemini 키를 직접 저장하고 무료 프로젝트 조건을 확인한다. 노트는 온라인 생성, PDF는 오프라인 로컬 변환이다. 앱 종료/새 전사 전 PDF를 다운로드한다. 생성 실패는 수동 재시도, PDF 실패는 변환만 재시도하며 비용/무료 한도 초과에 자동 유료 전환하지 않는다.
