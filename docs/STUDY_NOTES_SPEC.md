## 범위와 우선순위

로컬 ASR의 Base/Small/Turbo 선택, 최대 100자 힌트, 문장별 표시, 시간 없는 전사문 Markdown 다운로드, 반복·힌트 대체·연속 저신뢰도 복구, 원래/재시도 보존 및 수치 진단을 유지한다. 새 노트는 별도 결과로 생성하며 전사문을 수정하지 않는다. 기존 ASR 모델 선택과 달리 노트 모델 선택 UI는 없다.

이 문서의 N01~N39가 새 기능의 사용자 결정 원본이다. 기존 문서의 외부 AI/노트 제외는 전사 전용 구현의 범위 기록이며, 새 설계에는 이 문서의 제한적 예외가 우선한다. AI 교정, 채팅, 웹 검색, 자동 요약, 영구 보관함, 본문 편집, 유료 자동 전환은 추가하지 않는다.

## 표시 및 수명

생성 전 안내: “노트 생성 시 전사문이 Google Gemini로 전송됩니다. 녹음 파일은 전송하지 않습니다.” 무료 API 입력·출력이 제품 개선에 사용될 수 있다는 안내를 함께 표시한다. 실제 이용 조건은 모델 확정 단계에서 공식 정책을 재확인한다. 기본 전사 흐름에서는 외부 AI 요청이 일어나지 않는다.

세 종류별 생성 버튼은 최초 생성과 다시 생성으로 구별한다. 다른 탭/종류로 이동해도 실행 작업은 유지한다. 하나의 종류를 재생성하는 동안 기존 결과를 계속 열람·다운로드할 수 있다. 성공 시에만 최신 결과로 원자 교체한다.

새 녹음·전사 입력 변경·재전사로 결과를 버릴 때 노트가 있으면 손실 확인을 거친다. 취소하면 현재 작업과 결과를 유지한다. 노트 생성 중에는 해당 변경을 차단한다. 제목 변경은 로컬 표시 정보만 바꾸고 이미 저장한 PDF 파일까지 바꾸지는 않는다.

기술 기본값: 세션 메모리 보관. 기존 전사 완료 30분 만료 정책과 노트 수명을 연결해야 한다. 노트 기능 사용 세션에서는 진행 중 만료 금지, 마지막 사용자 활동 후 30분 유휴 만료로 설계하고 UI에 안내한다. 현재 앱에 이미 적용된 동작으로 표현하지 않는다. 자동 영구 저장·새로고침 복원·버전 보관함은 없음. 기존 로컬 복구 기록은 별도이며 삭제하지 않는다.

## PDF 가독성·응용 문제 근거 수정 (2026-11-09)

사용자 요청으로 PDF에서는 강의 근거 시간 문자열을 표시하지 않는다. 근거 ID 검증/내부 매핑과 화면의 근거 표시는 유지한다. 보충 설명·응용 문제·확인 필요는 PDF에서도 유지한다. 초록색 소제목 앞 16pt 여백으로 이전 주제와 한 줄 정도 구분한다. 기존 다운로드 파일은 변경하지 않으며 새 PDF 변환에 적용한다.

문제풀이 실패 두 건은 NOTE_SCHEMA_INVALID/questions.6.source_ids/too_short로, HTTP 429가 아니라 7번째 문제의 빈 근거 목록을 거절한 로컬 검증이었다. 당시 basis 값은 기록하지 않아 해당 문제의 lecture/supplement 분류는 확정할 수 없다. Question/Answer의 무조건 min_length=1 제한을 없애고 공통 의미 검증에서 lecture는 여전히 근거 필수, supplement는 빈 근거 허용으로 정합성을 맞췄다. 존재하지 않는 ID는 어느 유형에서도 거절한다. notes-v3 지시문 반영. 관련 테스트 15개 통과. 실제 문제풀이 재생성은 하지 않았으며 사용자 사례 해결 여부는 다음 생성으로 확인한다.

## 문제풀이용 도입 설명 제외 (2026-11-09)

사용자 요청으로 문제풀이용은 앞쪽 개념 설명·요약을 제외하고 문제 다음 정답·해설 순서로 제공한다. 기존 정답/해설 제공 결정은 유지한다. notes-v4 프롬프트는 practice.sections=[]를 요구하며, 앱도 문제풀이용 sections를 제외해 화면/PDF에 같은 정책을 적용한다. 이해용·암기용은 유지. 관련 모의 테스트 17개와 JS 구문 검사 통과. API 호출 없음. 기존 다운로드 PDF는 자동 변경하지 않으며 실행 중 서버에는 재시작 후 적용된다.

## 안내 문구 제거 (2026-11-09 사용자 변경 요청)

노트 생성 부근의 Gemini 전송·무료 데이터 활용 안내, 결과 수명·PDF 보관·근거 시간 안내, 하단 음성 외부 미전송 문구를 화면에서 제거한다. 기존 N10의 상시 안내 표시는 이 최신 요청으로 대체한다. 외부 전송 시점·대상, 결과 수명, 개인정보 처리 및 기능 동작은 변경하지 않는다.

## 좌측 상단 설정 메뉴 (2026-11-09)

사용자 요청으로 Gemini API 키 설정을 강의노트 본문에서 제거하고 앱 제목 왼쪽의 3줄 메뉴 버튼으로 이동했다. 초기에는 닫힌 좌측 설정 패널이며 클릭 시 열린다. 닫기/Escape/배경 클릭으로 닫고 메뉴 버튼에 포커스를 돌려준다. 저장·삭제 기능과 Windows 자격 증명 저장 방식은 유지한다. 메뉴를 닫으면 입력 중인 키 문자열은 비운다. 실제 키를 보여주거나 추가 API 생성 호출을 하지 않는다. 합성 키·모의 API 기반 Edge에서 기본 숨김/열기/저장/Escape/모바일 폭 표시와 기존 3종 PDF 흐름을 검증한다.
