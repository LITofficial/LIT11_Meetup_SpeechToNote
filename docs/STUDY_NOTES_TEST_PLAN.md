# 강의노트 검증·평가 계획 — 아직 미실행

> 최신 상태 (2026-11-09): 사용자 후속 요청으로 강의노트 구현이 승인되어 세 종류 생성·키 설정·취소·PDF 기능을 구현했다. 외부 API 실호출과 사용자 무료 프로젝트/노트 품질 검증은 아직 미실행이다. 기존 전사 기능은 유지한다. 아래의 설계만 승인/미구현 표현은 이전 단계 기록이며 현재 상태는 IMPLEMENTATION_STATUS.md의 마지막 항목을 따른다.

## 구현 전 확정할 항목

Gemini 무료 모델 ID/가용성, 프로젝트 결제 상태·quota, 입출력 토큰 한도, 구조화 응답 지원, SDK 재시도 해제 및 timeout 동작, 자격 증명 저장소 구현, 한글 폰트 라이선스/PDF 렌더러를 검증 후 고정한다. 특정 모델명·호출 횟수·속도·비용을 지금 보장하지 않는다.

## 자동 테스트 (모의 API 우선)

| 영역 | 필수 검증 |
| --- | --- |
| 회귀 | 기존 업로드·ASR 모델/힌트·복구·문장 표시·Markdown 다운로드·원문/진단 보존; 네트워크 차단 상태의 로컬 전사 |
| 근거 | 복구 없음/accepted/거절/혼합 결과에서 final_text와 최종 구간 일치; retry 절대 시간; 잘못된 source_id/시간을 근거로 표시하지 않음 |
| 동시성 | 더블클릭 1회 호출, ASR와 노트 교차 차단, 종류 전환 API 0회, 재생성 성공 교체/실패 보존 |
| 수명 | 새 녹음/재전사 손실 확인, 취소 시 보존, 오래된 snapshot 거절, 진행 중 만료 방지, 종료/유휴 정리 |
| 취소 | 시작 전/전송 후/완료 경쟁, 180초 timeout, 늦은 응답 폐기, 자동 재시도/이어쓰기 없음 |
| 입력/출력 | 전체 입력 한도 초과 사전 거절·무절단, 빈 결과/길이 종료/차단/잘못된 JSON 거절, 문제-정답 대응 |
| 비밀정보 | 키 조회/로그/URL/클라이언트 영구 저장 금지, 저장 실패 평문 fallback 없음, 키 변경/삭제, 세션/CSRF/Host/Origin 검증 |
| 전송 | 클릭 전 외부 호출 0회, 음성/파일명/경로/원래·진단 로그 미전송, 텍스트+source_id+불확실성만 전송, 전사 내 지시 무시 |
| PDF | 변환 실패 후 기존 노트 보존, 재다운로드 AI 호출 0회, 제목 변경 AI 호출 0회, 파일명/HTML 주입 방어 |

기존 37개 테스트 통과는 전사 기능의 과거 검증이며 위 신규 테스트를 통과했다는 뜻이 아니다.

## 실제 검증 순서

1. 별도 구현 요청 후 모의 응답으로 이해용 전체 흐름과 오류/취소를 확인한다.
2. 사용자가 앱에 직접 키를 입력한다. 결제 및 무료 제공 조건을 확인한다. 채팅/저장소에 키를 남기지 않는다.
3. 외부 전송 가능한 약 3분 샘플 최종 전사문으로 이해용 생성·화면·PDF를 검증한다. 암기용·문제풀이용 추가 후 같은 샘플로 3종 확인. 내용 부족 시 10문제 미만은 정상이다.
4. 동일한 49분 전사 snapshot과 프롬프트 버전으로 3종 품질을 함께 검토한다. 재전사 결과가 바뀌면 모델 비교 입력으로 혼용하지 않는다.
5. 핵심 누락·강의와 다른 사실·불확실성 은폐·부적절한 보충 표시·틀린 정답이 있으면 원인을 전사/프롬프트/모델로 구분한다. 지시문 변경 후 해당 문제를 재평가한다. 해결되지 않으면 유료 모델 비교를 사용자와 결정한다.

정확성 우선 평가표: 핵심 개념 목록 및 포함 여부, 강의 근거 ID의 타당성, 전공 용어와 확인 필요 표시, 보충/응용 구분, 문제의 충분한 조건과 정답·해설 일치, 읽기 편의성, 생성 시간, timeout/한도 오류. 항목별 통과/수정 필요와 근거 예시를 기록한다. 중대한 사실·정답 오류가 남은 상태를 데모 품질 합격으로 선언하지 않는다. 점수만으로 자동 합격하지 않으며 사람이 검토한다.

PDF는 한글·영문·표·긴 문단·여러 페이지·문제/해설의 실제 렌더 결과를 페이지별 확인한다. 화면과 제목/내용/근거/경고가 일치하고 잘림·깨진 글꼴·누락이 없어야 한다. PDF 재시도는 외부 API 호출 없이 성공해야 한다.

실제 전사·노트·PDF·평가 예시는 저장소 밖 또는 Git 제외 로컬 자료로 관리한다. 이번 설계 작성에서 샘플 읽기/전송, API 호출, 패키지 설치, PDF 생성은 수행하지 않았다.
