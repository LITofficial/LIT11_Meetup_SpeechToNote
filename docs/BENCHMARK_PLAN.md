# 데모 모델 확인

> 최신 상태 (2026-11-09): 사용자 후속 요청으로 강의노트 구현이 승인되어 세 종류 생성·키 설정·취소·PDF 기능을 구현했다. 외부 API 실호출과 사용자 무료 프로젝트/노트 품질 검증은 아직 미실행이다. 기존 전사 기능은 유지한다. 아래의 설계만 승인/미구현 표현은 이전 단계 기록이며 현재 상태는 IMPLEMENTATION_STATUS.md의 마지막 항목을 따른다.


목적은 시연 PC에서 base와 small 중 사용자가 선택한 모델이 실제 동작하는지, 시연 가능한 대기 시간인지 확인하는 것입니다. 두 모델을 모두 선택할 수 있도록 준비합니다.

같은 1~5분 한국어 음성으로 각 모델을 실행하고 모델 ID·revision, 엔진 버전, 파일 길이, 초기 로딩 포함 시간, 전공용어 누락과 오인식 사례를 기록합니다. 가능한 경우 일부 정답 전사문과 비교합니다.

기준 PC는 i5-8250U·RAM 약 12GB이며 별도 NVIDIA GPU가 확인되지 않았습니다. CPU int8를 우선 검증합니다. base 기본값은 속도를 고려한 설계 가정이고, 실제 속도·정확도는 미측정입니다.

90분/30분이나 정량 정확도 문턱을 데모 출시 조건으로 두지 않습니다. 발표용 샘플의 처리 시간이 너무 길면 더 짧은 샘플을 사용하거나 선택 모델을 조정하고 실제 결과를 설명합니다. 완료된 결과를 실시간 처리인 것처럼 보여 주지 않습니다.
