# 녹음만 했을 뿐인데, 나만의 AI 노트가?

*Whisper와 Gemini API를 활용한 개인 맞춤형 강의 학습 노트 만들기*

---

오프닝

안녕하십니까? 저희가 이번 발표에서 소개할 내용은 ‘녹음만 했을 뿐인데, 나만의 AI 노트가?’인데요. 강의 녹음과 같은 음성 데이터를 텍스트로 변환하는 과정을 보여드리고, 이를 어떻게 활용할 수 있을지 소개해보도록 하겠습니다.

먼저 짧은 영상 하나를 보시겠습니다.

(슬라이드 2)

(30초 정도 개념 설명 강의 영상을 재생)

(슬라이드 3)

방금 들으신 강의 내용 중 얼마나 기억하고 계신가요? 영상이 짧아 대략적인 내용은 기억하실 수 있겠지만, 세부적인 내용 하나하나 기억하기는 어려울 수 있습니다. 

(슬라이드 4)

만약 강의 내용이 1시간을 넘어가는 대학 강의는 어떨까요?  교수님의 설명을 놓치지 않으면서 중요한 내용을 필기하고, 설명을 이해하는 일을 동시에 수행하기엔 상당히 어렵습니다. 

(슬라이드 5)

때문에 저희는 강의 중에 작성한 노트나 수업 자료, 강의 내용을 녹음한 녹음 파일을 활용해 내가 놓친 부분이나 이해를 못한 부분을 다시 공부하곤 합니다. 

문제 정의

이중 녹음 파일을 활용해 공부하게 되면 (슬라이드 6) 수업 내용을 그대로 보관해 내가 놓친 부분을 짚고 넘어갈 수 있지만, 녹음 파일을 다시 재생하면서 해당 부분을 직접 찾아야 한다는 단점이 있습니다.

그럼 녹음 파일에 담긴 내용을 조금 더 쉽게 활용할 방법은 없을까요?

(슬라이드 7)

저희는 이러한 문제를 해결하기 위해  음성을 텍스트로 변환하는 전사 기술에 주목하게 되었습니다. 

(슬라이드 8)

음성을 전사하게 되면 녹음파일에서는 어려웠던 텍스트 검색이 가능해집니다. 때문에 녹음 파일을 다시 틀면서 내가 원하는 부분 나올 때까지 다시 돌려가며 찾는 것보다 빠르게 원하는 부분을 찾을 수 있습니다.  

(슬라이드 9)

뿐만 아니라 생성형 ai를 활용하면 전사된 텍스트를 바탕으로 내용을 요약하거나, 필요한 부분을 따로 정리하는 추가적인 활용 또한 가능할 것입니다. 즉, 전사를 하게 되면 단순히 음성을 글자로 바꾸는 것에서 끝나지 않고, 녹음된 강의 내용을 다양하게 활용하기 좋은 출발점이 되게 됩니다.

(슬라이드 10)

따라서, 오늘은 이러한 전사를 도와주는 음성 인식 오픈 소스 모델인 Whisper를 사용해 강의 녹음 파일을 전사하고, 나아가 전사된 텍스트를 활용할 방법을 소개해 보겠습니다.

본론

1. STT란?

(슬라이드 11)

먼저 음성 인식 기술인 STT에 대해 간단하게 알아보겠습니다. 

(슬라이드 12)

여러분은 TTS에 대해 들어보신 적 있으신가요? 우리가 쇼츠나 릴스를 보다보면 AI목소리로 영상을 설명하는 것을 보신 적이 있을 겁니다. 이처럼 글자를 음성으로 바꾸는 기술을 Test-to-Speech, TTS라고 합니다.

반대로 음성을 텍스트로 바꾸는 기술이 바로 STT입니다. 유튜브 영상에 자동으로 자막이 생기거나, 음성으로 메세지를 입력하는 것이 STT 기술을 활용한 대표적인 사례라고 보시면 될 것 같습니다.  

(슬라이드 13)

저희는 STT 기술을 직접 구현하기 보단, open ai가 공개한 whisper 음성인식 모델을 활용해보았습니다. 

1. whisper란

(슬라이드 15)

이어서 whisper에 대해 소개해 보겠습니다.

(슬라이드 16)

whisper는 다양한 언어의 음성을 텍스트로 변환할 수 있는 음성 인식 모델입니다. 한국어 뿐만 아니라, 영어, 일본어 등 여러 언어를 지원하며, 다양한 음성 환경을 학습했다는 특징이 있습니다. 

저희가 여러 음성 인식 기술 중 whisper를 선택한 이유는 바로 오픈소스라는 점입니다. 

(슬라이드 17)

일반적인 음성인식 기능은 외부 서비스에서 제공하는 API를 이용하지만, 서비스에서 정한 사용량이나 요금 정책에 영향을 받게 됩니다. 

(슬라이드 18)

반면, whisper는 모델을 직접 내려받아 로컬 환경에서 실행할 수 있습니다. 즉, 별도의 외부 음성 인식 api에 녹음 파일을 전송지 않고도 음성을 텍스트로 변환할 수 있습니다. 

1. 전사 과정

(슬라이드 19)

whisper에 음성 데이터를 입력하게 되면 

(슬라이드 20)

컴퓨터 내에서는 전처리, 특징 분석, 텍스트 출력, 이렇게 세가지 과정을 거치게 됩니다.

(슬라이드 21)

조금 더 세부적인 내용을 다뤄보겠습니다. 먼저 사용자가 강의 녹음 파일과 같은 음성 데이터를 입력합니다. 

(슬라이드 22)

여기서 이 음성 데이터는 시간에 따라 변하는 파형으로 저장되어 있어 특정 시간에 어떤 주파수의 소리가 얼마나 포함되어 있는지 쉽게 파악하기 어렵습니다. 예시를 위해 발음이 비슷한 “발”과 “말”의 파형을 비교하며 설명해보겠습니다.

(슬라이드 23)

보시면 왼쪽이 ‘발’, 오른쪽이 ‘말’을 발음 했을 때 데이터에 저장된 파형입니다. 두 파형 모두 시간에 따라 소리의 크기가 변하는 모습은 보여주지만, 이것만으로 두 단어가 어떻게 다른지 파악하기가 어려워 보입니다.

때문에 whisper는 음성 데이터 속 특징을 보다 효과적으로 분석할 수 있도록 데이터를 멜 스펙트로그램으로 변환합니다. 

(슬라이드 24)

멜 스펙트로그램은 시간에 따른 주파수 정보를 시각적으로 표현한 것으로, 사람의 귀가 소리를 인식하는 특성을 반영해 주파수 정보를 변환합니다. 

(슬라이드 25)

이건 아까 보여드린 파형을 멜 스펙트로그램으로 변환해 놓은 그래프 입니다.  발음하는 방법이 달라지면 음성에 포함된 주파수의 분포와 시간에 따른 소리의 변화에도 차이가 나게 됩니다. 

이렇게 멜 스펙트로그램으로 변환한 데이터는 각 발음별 어떤 특징이 있는지 분석하기 편하므로 whisper는 녹음파일을 멜 스펙트로그램으로 전처리 후,

(슬라이드 26)

특징 분석 및 실제 텍스트 예측을 위해 whisper 인코더와 디코더 전달하게 됩니다. encoder는 입력받은 데이터에서 정보를 추출하고, decoder는 그 정보를 바탕으로 실제 텍스트를 생성합니다.

(슬라이드 27)

인코더가 하는 역할을 더 자세히 설명하기 위해 전에 보여드린 발, 말에 대한 멜 스펙트로그램 데이터로 설명해 보겠습니다. 발에선 처음 0.2초정도 에너지가 낮은 구간 이후 에너지가 급격히 증가하고, 규칙적인 수평 배음 구조가 나타납니다. 

(슬라이드 28)

반면 말에선 발과 다르게 처음 0.3초정도 비음의 특징인 공명 특성이 나타나고, 이후엔 비슷하게 “ㅏ”를 발음하면서 뚜렷한 수평 배음 구조가 보이는 것을 알 수 있습니다. 

(슬라이드 29)

이런식으로 데이터에 담긴 발음, 속도, 세기, 쉬는 구간 등 여러 특징을 추출해 하나의 정리 노트를 만들어서 decoder에 전달하게 됩니다. 

(슬라이드 30)

decoder는 사람이 대화를 하는 것과 비슷한 역할을 합니다. 

(슬라이드 31)

저희가 대화를 나눌 땐 현재 대화 맥락과 현재 

그 사람이 하고 있는 말을 토대로 다음 상대방이 할 말을 예측하곤 하잖아요? 

(슬라이드 32)

decoder도 이와 비슷하게 encoder가 정리한 요약 노트와 앞에서 자신이 써 놓은 앞 부분을 보면서 다음에 올 단어를 순차적으로 써내려갑니다.  

(슬라이드 33)

마지막으로 예측된 결과를 텍스트 형태로 출력해 전사를 완료하게 됩니다.

(슬라이드 34)

정리하면 처음 입력된 데이터를 멜 스펙트로그램으로 전처리 후, 인코더에 전달해 음성의 특징을 분석하고, 이걸 다시 디코더에 전달에 그 정보와 앞서 생성한 텍스트를 바탕으로 다음에 올 내용을 순차적으로 예측합니다. 이렇게 예측된 결과가 연결 되면서 최종적으로 우리가 읽을 수 있는 텍스트가 만들어집니다.

(슬라이드 35)

이렇게 만들어진 전사문은 녹음 파일이랑 다르게 텍스트 검색이 가능해져 내용을 빠르게 찾을 수 있게 되었지만, 여저히 이 전사문 자체는 너무 깁니다.

(슬라이드 36)

때문에 찾고자 하는걸 검색해서 사용자가 원하는 부분을 찾는건 여전히 부담스러울 수는 있습니다. 

4, 활용 방안

(슬라이드 37)

이러한 부담을 줄이고자 생성형 Ai를 활용해 전사문을 정리하는 방법을 보여드리겠습니다. 

(슬라이드 38)

방법은 간단한데, 바로 대규모 언어 모델인 LLM을 이용하는 것입니다. 

(슬라이드 39)

LLM은 방대한 텍스트 데이터를 학습한 인공지능 모델로 문장 사이 문맥과 의미를 파악해 새로운 텍스트를 생성하는데 좋습니다. 

(슬라이드 40)

때문에 단순히 문장을 짧게 요약하는 것 뿐만 아니라 강의 내용 중 중요한 개념, 연관 내용 정리 등에도 사용할 수 있습니다.

(슬라이드 41)

또한, LLM 모델에 넣을 지시서인 프롬프트를 다르게 하면 사용자의 공부 스타일을 반영할 수도 있습니다. 

(슬라이드 42)

예를 들어 시험을 준비하는 학생이라면 핵심 용어와 정의를 중심으로한 암기용 노트를,

문제를 직접 풀어보며 공부하는 학생이라면 연습 문제와 풀이 과정을 생성할 수도 있습니다.

이처럼 동일한 강의 전사문으로 사용자가 원하는 형태로 다양한 학습 자료를 만들 수 있고,

이 자료를 한곳에 모아 나만의 학습 노트를 만드는 것 또한 가능합니다.

(슬라이드 43)

이제 저희가 직접 구현한 프로그램으로 시현을 해보도록 하겠습니다.
